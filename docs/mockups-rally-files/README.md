# Rally files: menu mock-up

`menu.html`: the menu redrawn around the rally file (`docs/rally-file.md`). Open it in a browser. The covers load
from the ARA pack beside the repo (`../../../Rally Files/ARA Nationals 2026/covers/`); without the pack, every
picture falls back to a drawn rally plate. Crew names are made up. Stage names, lengths and times are real.

1. **Rallies**: one card per import. A season is one card with a mosaic of its covers, a loose rally and a single
   stage get a drawn plate, and "Add" is one quiet strip.
2. **Season**: the eight rounds as cover cards, plus a Standings tab (top 10 and you, points per round).
3. **Rally**: a photo-and-logo banner, then stages in running order. A stage run twice is one row ("SS2 · SS4"),
   and Place shows your best against the real field. Tabs: Results (once every stage is driven) and Rules
   (five lines at most, hidden when the file has none).
4. **Stage**: today's page, plus a Leaderboard card with a pass toggle, the top 10 and your row. It also has the
   "not placed" states: no time yet, line not as run, pass cancelled.

"Now / Proposed" switches screens 1, 3 and 4 to today's menu.

## For you to decide

1. **Place on the rally list**: your best place over both passes (drawn), or always the first pass?
2. **Season card picture**: a mosaic of the round covers (drawn), or the next round's cover alone?
3. **Rules tab**: the ARA pack has no rules block, so the tab is hidden for it. Should we keep the tab, and show
   only the false start (the one rule the game uses), or show all five?
4. **Stage page**: should the leaderboard push "Your runs" down to two runs (drawn), or should the two share one
   card with Leaderboard / Your runs tabs?
5. **Class column**: the real crews' class (RC2, L4WD...) is shown, and yours is blank. Should we drop the column,
   or later let you pick a class to compare within?
