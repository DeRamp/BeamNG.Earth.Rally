# Install

You need **BeamNG.drive 0.40.5** and two downloads.

1. **BeamNG.Earth.** Install it from [the DeRamp fork](https://github.com/DeRamp/BeamNG.Earth/releases) with its
   installer. The fork adds what **Auto recce** needs. Official BeamNG.Earth 1.6+ also works, without Auto recce.
2. **Earth Rally.** Download `earth_rally-1.6.0.zip` from
   [Releases](https://github.com/DeRamp/BeamNG.Earth.Rally/releases/latest).
3. Put the zip, **still zipped**, in `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\`.
4. Start the game through BeamNG.Earth's launcher, then **Freeroam > BeamNG.Earth**.
5. Press **Ctrl + Alt + K**. The Earth Rally menu opens.

![The Rallies page](https://raw.githubusercontent.com/wiki/DeRamp/BeamNG.Earth.Rally/images/menu-rallies.jpg)

## Updating

* Delete the old `earth_rally-*.zip` first. Two copies both load.
* Your rallies, lines and times stay. They live in `…\current\earthRally\`, not in the zip.

## Optional: the ARA 2026 pack

The [1.6.0-alpha release](https://github.com/DeRamp/BeamNG.Earth.Rally/releases/tag/v1.6.0-alpha) carries
`ARA-Nationals-2026.zip`: the American Rally Association's 2026 season, 8 rallies and 64 stages, with real results.
Unzip it into `…\current\earthRally\import\`. A folder pack is the tested way; a zipped one should work too.
