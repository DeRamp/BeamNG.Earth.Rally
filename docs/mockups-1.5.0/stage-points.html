3 · the three states

One cell each. Told apart three ways, none of them colour: the small icon (pin / die / slashed circle), the word, and the cell itself (solid / dashed edge / darker and flat). The count is only ever shown for points from the map: the API gives no count for random ones, and “about 9” would be a guess.

4 · in the stage list? (drawn, not recommended)

It fits: in the Name cell after the name, four 18px icons with a count are about 170px, and the Name cell is about 856px at 1920 against a longest real name of about 460px. But it is not recommended: the icons cannot carry words in a 58px row, so a player has to learn that bright = map, grey = random, dark = none — exactly the colour-only reading the page avoids — and it would sit on every row of every rally, while the list's job is “can I drive this”. Every row would look the same on most rallies (7 of 9 mark little or nothing). The stage page is where it belongs.
